Offline web app that turns any photo and caption into GTA 6-style cover art and exports it as a PNG — three templates, four colour grades, draggable photo, editable text and decorations. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty.

## Run it

```sh
node main.ts
```
